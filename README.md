# Telegram Bot для автоматических комментариев в канале

Бот автоматически оставляет комментарий с картинкой и двумя кнопками под каждым новым постом в Telegram-канале. Комментарий появляется как "Начало обсуждения" (первый комментарий).

## Как это выглядит

Под постом в канале появляется:
- 🖼️ Картинка товара
- 📝 Текст с артикулом
- 🔘 Кнопки

## Пошаговая настройка

### Шаг 1: Создайте бота через @BotFather

1. Откройте Telegram и найдите **@BotFather**
2. Отправьте команду `/newbot`
3. Придумайте **имя** бота (например, `Мой комментатор`)
4. Придумайте **username** бота, который заканчивается на `bot` (например, `my_comment_bot`)
5. После создания BotFather пришлет **токен**. Сохраните его — он выглядит так: 123456789:ABCdefGHIjklMNOpqrSTUvwxYZ

### Шаг 2: Подготовьте канал и группу обсуждения

1. **Создайте или подключите группу обсуждения** к каналу:
- Зайдите в настройки канала
- Раздел **"Обсуждение"**
- Выберите существующую группу или создайте новую

2. **Добавьте бота в группу обсуждения**:
- Зайдите в группу
- Нажмите на название группы → **"Добавить участников"**
- Введите username вашего бота (например, `@my_comment_bot`)

3. **Получите ID канала и группы**:
- Добавьте бота **@getmyid_bot** в группу обсуждения
- Напишите в группе любое сообщение (например, "тест")
- Бот пришлет вам ID группы (число вида `-1001234567890`)
- Добавьте **@getmyid_bot** в канал как администратора
- Напишите в канале любое сообщение
- Бот пришлет ID канала
